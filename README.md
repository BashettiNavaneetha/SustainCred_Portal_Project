# SustainCred Portal Project 🌐  

This project is a simple **web portal** that allows users to register, log in, and manage their resumes. The portal provides different navigation options based on whether the user is logged in or not.  

---

## 🔑 Features  

### Before Login/Register  
- **Home** – Welcome page of the portal  
- **Login** – Existing users can log in to their account  
- **Register** – New users can sign up and create an account  

### After Login  
- **Home** – Redirects to the user’s main dashboard  
- **Upload Resume** – User can upload their resume in supported formats  
- **Download Resume** – User can download their previously uploaded resume  
- **Delete Resume** – Option to remove the uploaded resume  
- **Logout** – End the session securely  

---

## 📂 Project Structure  
- **Frontend**: HTML, CSS (basic styling)  
- **Backend/Functionality**: Handles user authentication and file operations  
- **Resume Management**: Upload, download, and delete options available only to logged-in users
